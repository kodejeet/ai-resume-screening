About AI Resume Screening

Technical overview and architecture documentation.

Project Purpose & System Architecture

This application is designed as a recruitment intelligence tool. It processes candidate resumes (PDF, DOCX, or plain text) alongside job descriptions to evaluate candidate fit using deep two-stage AI analysis.

Document Parsing

Uses pypdf and python-docx to parse uploaded files server-side into clean, plain-text streams.

Google Gemini AI Engine

Two-stage analysis: Stage 1 extracts structured JD requirements, Stage 2 evaluates the candidate with evidence-based skill matching and weighted scoring.

Key Security

API keys are securely loaded from server .env variables and never exposed to the client browser.

Evidence-Based Validation

Backend Python validates every AI conclusion against the original resume and JD text, preventing hallucinated skills or fabricated experience.
